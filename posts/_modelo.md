Este ficheiro é o modelo e nunca é publicado (começa por _).

Para criar uma atualização:
1. Copia este ficheiro e dá-lhe o nome AAAA-MM-DD-nome-curto.md (ex.: 2026-12-01-forja-nivel-2.md).
2. Preenche o cabeçalho entre os dois "---". "capa", "capa_texto" e "resumo" são opcionais: apaga a linha se não usares.
3. Enquanto "rascunho: sim" estiver lá, a atualização não aparece no site. Apaga essa linha para publicar.
4. Escreve o texto aqui em baixo. Imagens vão para posts/img/.
